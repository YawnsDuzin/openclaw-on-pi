# hello (demo skill)

본 스킬은 OpenClaw 설치 직후 **메시지 → 스킬 매칭 → 모델 호출 → 채널 응답** 파이프라인이 살아있는지 검증하는 최소 데모다.

## 동작

사용자 메시지가 (대소문자 무시, 앞뒤 공백 제거 후) 정확히 `hello` 이면:

- `ok` 한 단어만 응답한다.
- 도구 호출 (셸 / 파일 / 브라우저 / 세션) 을 *전혀* 사용하지 않는다.
- 외부 네트워크를 *전혀* 호출하지 않는다.

그 외 메시지에는:

- 본 스킬은 응답하지 않는다 (다른 스킬 / 기본 에이전트가 처리).

## 절대 규칙

- 파일 R/W 금지
- 셸 실행 금지
- 외부 도메인 호출 금지
- 한 글자라도 다른 응답 금지 — 정확히 `ok` (2글자 + 끝)

## 검증 기준

`bash run.sh` 가 다음을 자동 점검:

1. `~/.openclaw/skills/hello/SKILL.md` 가 설치되었는지
2. `openclaw agent --message "hello"` 응답이 정확히 `ok`
3. gateway 로그에 `skill=hello` 매칭 줄 존재

세 줄 모두 통과 시 종료 코드 0.
